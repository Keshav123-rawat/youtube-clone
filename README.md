# YouTube Clone Project

Full-stack YouTube clone built with React, React Router, Axios, Node/Express, JWT and MongoDB.

## Main functionality

- Home page with responsive header/sidebar/video grid
- Search by video title/channel
- 6+ dynamic category filters
- Register/login with validation and JWT
- Channel creation and public channel pages
- Video Create, Read, Update and Delete
- YouTube embedded video player
- Persistent Like/Dislike reactions
- Persistent Subscribe/Unsubscribe
- Comments Add, Read, Edit and Delete
- Comment ownership protection
- Account deletion and related data cleanup
- Responsive layouts

## Run

Backend:-

```bash
cd server
npm install
# create .env from .env.example
npm start
```

Frontend:-

```bash
cd client
npm install
npm run dev
```

See `client/README.md` for setup details.
